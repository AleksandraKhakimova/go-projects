# BeautyCatalog

Консольное и оконное приложение для каталога косметических продуктов на Go с базой данных SQLite.

## Возможности

- Добавление продуктов (крем, духи, помада)
- Просмотр всех продуктов
- Фильтр по категории
- Фильтр по максимальной цене
- Поиск по названию
- Применение скидки ко всем продуктам
- Статистика (количество и средняя цена по категориям)
- Корзина покупок
- Графический интерфейс (Fyne)
