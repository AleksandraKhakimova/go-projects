# GoChat

Простой мессенджер с сервером на Go и PostgreSQL.

## Возможности

- Регистрация пользователей с паролем
- Отправка сообщений другим пользователям
- Просмотр входящих сообщений
- История переписки с конкретным пользователем
- Сервер принимает несколько клиентов одновременно

## В проекте доработать надо
- Сайт был доступен для всех пользователей
- Голосовые, кружочки, видео, фото
- Уситить защиту пользователя
